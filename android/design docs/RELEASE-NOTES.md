# Latest firmware — 2.5 Merthsoft.13

October 9, 2026. Scale-aware grids, optional MIDI keyboard following and beat sync.

- SEL/LFO/ENV grids show actual mapped pitches with key-appropriate accidentals;
  C minor shows Eb/Ab/Bb. SEL root-selection hints distinguish its held action.
- HOME menu SYSTEM knob 2: MIDI SCALE OFF / KEYBOARD, persisted and off by default.
  It applies receiving-track keyboard pitch mapping to USB/TRS synth input. Captured
  pitches survive scale/track/setting changes; collisions release on the last MIDI
  owner. Drums/GM kits remain literal; chord voicings are not generated by this option.
- Vibrato/tremolo knob 4 replaces fade with OFF or all nine step divisions. Knob 1
  returns to free Hz. Playing cycles follow transport phase; stopped cycles use BPM.
- Includes Merthsoft.12 preserved scale-guide/backlight behavior in LFO/ENV panels.
- README/guide/component docs updated, with fresh production-code framebuffer renders.
