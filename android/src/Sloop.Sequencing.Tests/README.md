# Package-free verification

This executable exits nonzero on assertion failure and covers musical preservation,
selection boundaries, identities, transactions, stale proposals, full undo/redo,
locked edits, firmware capacities/ranges, native data retention, drum variation,
and tie/slide boundaries including loop wrap. Run with `dotnet run --project` or
`./Verify.ps1`. It does not require Android workloads or a test-framework package.
