# Selected note chain actions

Include `note_chain_actions.c` after `note_ties.c`. Selection uses an explicit attack's onset and MIDI pitch (including 0 and 127), never a retained slot.

`note_chain_pitch(t,onset,pitch,target,write)` transposes one complete chain. `note_chain_place(t,onset,pitch,dest,move,write)` copies it, or moves it when `move` is nonzero. Call with `write=0` before capturing undo; `write=1` independently repeats full validation before mutation. The caller must serialize commit against other structural edits. Success returns 0; refusals return -1 collision, -2 four-slot capacity, -3 invalid attack, -4 overlapping voices require POLY, -5 pitch/pattern bounds, -6 source onset has locks. Negative results leave all track bytes unchanged.

There is no wrapping or truncation. Same-pitch reattacks end chains. A move can overlap its own sustain; a copy cannot occupy its source pitch. Existing destination voices keep their packed dynamics and shared velocity/accent. An isolated placed voice receives the source attack velocity/accent, packed level and onset ratchet; continuations use the attack level and no ratchet, matching native tie extension. Pitch edits preserve each cell's packed expression exactly.

Microtiming, fill, slide and locks stay at their original steps. Moving one voice does not move shared automation. Source-onset locks cause MOVE/COPY refusal; pitch edits retain them. Legacy ties affected by the edit, including a following legacy run, become explicit continuation cells so unrelated pitches retain their original duration and attacks. No persistent state or pattern-sized staging buffer is added: validation and commit each stream at most 64 cells and four voices, with a few ten-byte step temporaries.

`tests/note_chain_actions_test.c` runs the real native helpers against an independent effective-cell model, tests atomic refusals against whole-track bytes, overlapping moves in both directions, all four slots, reattacks, destination expression ownership, locks, POLY, MIDI extremes, short patterns and 1,200 randomized mixed legacy/independent patterns. An edited overlapping-move/copy fixture also runs through the production sequencer and asserts balanced MIDI with no outstanding notes after STOP. The isolated WSL host regression passes. Full UI undo, target flash fit and hardware behavior remain integration gates.
